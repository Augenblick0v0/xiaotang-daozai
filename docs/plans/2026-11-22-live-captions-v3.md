# 实时字幕 v3：滚动、跟随与识别稳定性

日期：2026-11-22 · 分支：`feat/live-captions` · 前置：`2026-11-22-live-captions-v2.md`

## 问题与根因（Observed）

| # | 用户现象 | 根因 |
|---|---|---|
| 1 | 滚到底再滚，文字闪 | 滚轮位移每次都被乘 48 且没有按内容高度夹紧，滚到底时偏移越界又被 ScrollArea 拉回，形成一帧越界/一帧回弹 |
| 2 | 向上滚一下直接到顶 | 同上：一格滚轮约 50 点 × 48 = 2400 点，一屏只有 150 点，于是一次就冲到顶 |
| 3 | 展开页已到最新句，药丸还停在「…反油。」 | 药丸选行先找「完整句 + 有译文」，新句还没译文时会退回旧句，看起来永远慢一句 |
| 4 | 页面里下一句出现又消失 | 半句（partial）只在「未开翻译」时画；开翻译后 partial 被隐藏，定稿前就空一帧 |
| 5 | 视频里的音乐/音效反复出「使用简体中文。」 | 给 Whisper 的中文解码提示词 `以下是普通话的句子，请使用简体中文。` 被模型当成音频内容转录出来（提示词回显），背景声越杂越容易触发 |
| 6 | small 模型完全不出字 | `small` 权重从未下载到缓存（`models--Systran--faster-whisper-small` 不存在），侧车启动失败后没有回退，UI 只显示旧状态 |
| 7 | base 准确率偏低 | 模型太小 + 之前的提示词污染；切 small 是正确方向，但必须先保证权重可用 |

## 设计契约

1. **滚动一维状态**：`caption_scroll`（当前偏移）、`caption_max_scroll`（渲染回报的最大偏移）两字段；滚轮只做 `scroll` 点的一比一增减，再 `clamp(0, max)`。
2. **跟随与手动分离**：`caption_follow=true` 时渲染端钉底并把偏移写成 max；用户向上滚才置 false 并用记录的偏移；回到 `max-2` 内自动恢复跟随。
3. **药丸跟最新句**：岛上一律取 `view.lines` 最后一条非空原文；有译文就画第二行译文，没有就画「翻译中…」。不再为等译文停在旧句。
4. **半句可见**：partial 作为列表末尾的灰色一行，始终跟随（受 `caption_show_partial` 控制），定稿后由正式行替换。
5. **不注入解码提示词**：`DEFAULT_ZH_CONTEXT=""`，`resolve_context` 只返回调用方显式传入的 context；简体化只由 normalize 的 OpenCC 完成。
6. **模型可切换且可回退**：`small` 权重预下载到共享缓存；侧车加载失败时自动回退 `base` 并把实际模型写进 `WLK_READY` / `/health`，UI 显示实际生效的模型。
7. **验证不动鼠标键盘**：单测 + 侧车脚本 + `PrintWindow` 截图；不向扬声器放声。

## 工作分解

- T01 滚动状态机（app.rs / caption_ui.rs）——本次
- T02 药丸跟最新句（app.rs）
- T03 partial 常显（caption_ui.rs）
- T04 去提示词注入（server.py）+ normalize 单测
- T05 small 权重下载 + 失败回退（server.py）
- T06 `cargo test --lib caption`、`cargo check --all-targets --features record`
- T07 release 构建、静音 WAV 注入实拍、提交推送、覆盖本地运行版

## 验收

- 列表：滚到底继续向下滚画面不闪；向上滚一格只退约一行；长列表能停在中间。
- 药丸：展开页最新句出现后 ≤1 帧内药丸同步；无译文时显示「翻译中…」。
- 中文：视频背景音乐不再输出「请使用简体中文」。
- small：设置切 small 后能出字；若权重缺失自动回退 base 且 UI 显示 base。
