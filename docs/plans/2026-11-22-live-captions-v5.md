# 实时字幕 v5：滚动动画、固定字号换行、翻译时序与宽度设置

日期：2026-11-22 · 分支 `feat/live-captions`

## 用户要求（m04285）

1. 岛上按「从上到下」滚动：第一行正在识别 → 内容满后移到第二行 → 来第三行时做顺畅向上滑动动画，窗口切换为第 2、3 行。
2. 不自动缩小字号、不出现省略号：字号固定；下一个字符放不下就换到下一行。
3. 开启翻译后一直「正在听 / 翻译中」，翻译没真正跑；翻译仍用本地 NLLB 服务。
4. 只翻译「开启翻译之后」的新内容，不要把已有记录再翻一遍。
5. 翻译速度慢：可改成四行（原文两行 + 译文两行），或提供「岛宽度」可调项（仅系统实时字幕引擎有效）。
6. 美化：语言标签 `[ZH]` 与左侧吉祥物动画重叠。

## 设计契约

- C1 岛内容模型：维护 2 行原文窗口（`top`、`bottom`）。新句到达时 `top=bottom`、`bottom=新句`，并对旧内容做 0.22 s 向上位移动画（y 从 0→-line_height，透明度交叉）。
- C2 固定字号 12pt（开启翻译时原文 12、译文 11），按 `text_w` 硬换行（中文按字、英文按词），最多 2 行；不再 `fit` 缩字号、不再省略号。
- C3 译文窗口同样 2 行，与原文窗口一一对应；未译出的位置显示「翻译中…」但只在最底行。
- C4 岛高度：仅原文 2 行 = 56；原文+译文 4 行 = 96。宽度默认 440，可设置 360–720（仅 `caption_engine==1` 生效）。
- C5 翻译触发：只对「开启翻译后新出现的 final 句」入队；已存在的历史 id 不再翻译；队列只保留最新 1 条，过期任务丢弃。
- C6 语言标签区域固定宽度（`[ZH>EN]` 按最大宽度预留），吉祥物在左，文本起点 = max(标签右缘, 吉祥物右缘) + 8。
- C7 设置新增 `caption_bar_width: u16`（默认 440，范围 360..=720），保存/加载，界面滑杆仅在系统实时字幕引擎下显示。

## 工作分解

- T01 设置字段与 UI（model.rs / caption_ui.rs）。
- T02 岛两行滚动窗口与滑动动画（app.rs）。
- T03 固定字号换行渲染（app.rs）。
- T04 翻译时序：仅翻译新句、丢掉过期任务（caption.rs）。
- T05 语言标签与吉祥物避让（app.rs）。
- T06 单测：窗口滚动、换行函数、翻译入队策略。
- T07 构建、静音/真实音频验证、提交推送、更新本地运行版。
